# WCAG 2.2 AA Manual Audit Checklist

> Quarterly manual audit — see `docs/reporting.md` for cadence.

## Screen reader pass

- [ ] NVDA (Windows): assessment funnel
- [ ] NVDA (Windows): donation flow
- [ ] NVDA (Windows): AI assistant
- [ ] VoiceOver (macOS): assessment funnel
- [ ] VoiceOver (macOS): donation flow
- [ ] VoiceOver (macOS): AI assistant

## Keyboard-only navigation

- [ ] Full tab path through assessment funnel
- [ ] Full tab path through donation flow
- [ ] Full tab path through AI assistant
- [ ] Full tab path through SSO portal
- [ ] Full tab path through cemetery map
- [ ] No keyboard traps

## Focus state review

- [ ] Visible focus indicators on all interactive elements
- [ ] Focus order matches visual order
- [ ] No focus lost in dynamic content

## Colour contrast spot check

- [ ] All body text meets 4.5:1 ratio
- [ ] All large text meets 3:1 ratio
- [ ] All UI components meet 3:1 ratio
- [ ] Error states have sufficient contrast
